# Product Case Studies

Independent product work on real problems in Indian fintech and consumer tech. Each one follows the same path: **who the user is → what's actually broken → what to build first → how we'd know it worked.**

| Case study | Type | The question | My answer, in a line |
|---|---|---|---|
| [**Jupiter: an operating system for money**](./jupiter-money-os) | Product pitch (8-slide deck) | What should an "all-in-one" money app build next, when it already has every product? | Not another product. A resolution layer that wins trust when things break, and an AI "Money Autopilot" that connects the products it already has |
| [**Build vs. buy: fraud detection in lending**](./build-vs-buy-fraud-detection) | Decision framework | As a lending product scales, should fraud detection be built in-house or bought? | Buy the commodity baseline, build a thin layer on your own data, and let catch-rate data decide the long-term owner |
| [**Tatkal: the opening rush**](./irctc-tatkal-teardown) | Product teardown (8-slide carousel) | Why do users still miss Tatkal tickets, and what should be fixed first? | Separate system failures from sold-out quota first; then a waiting room with payment-timed seat holds that pass unpaid berths to the next person in line |
| [**Credit for India's gig workforce**](./gig-worker-credit) | Case study | How do you lend to workers with volatile income and no credit history? | Start with alternative credit scoring (Account Aggregator + platform data), then repayments that flex weekly, sold inside the gig app |

## What these show together

- **Domain range:** neobanking & payments, lending risk, financial inclusion, high-traffic consumer booking
- **Product craft:** problem framing, prioritisation, trade-offs, stakeholder alignment, phased roadmaps, success metrics
- **Where AI fits:** a context engine for personal finance, an in-house fraud signal layered on a vendor baseline, alternative-data credit scoring. In each one, AI is the means, not the pitch

*All four use only public information and my own analysis. They aren't affiliated with, or submitted to, any company named.*
